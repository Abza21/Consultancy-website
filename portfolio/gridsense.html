GridSense: Real-Time Utility Monitoring Dashboard

A live web GIS dashboard that shows faults and assets on a map.

Problem

Field teams and control-room staff had no single live view of faults across the network.

Solution

Built a PostGIS-backed web dashboard with Leaflet maps, live fault and asset layers, mobile-app data feeds and automated dispatch/alert workflows.

Result

Faults and assets are visible in one place, and alerts go out without manual steps.
